Six components, LTR above and RTL below, from the same markup with only dir changed. The layout mirrors because every rule uses logical properties — there is no RTL stylesheet. What must never mirror is called out in red.

Four ladders. Elevation says how far off the page something sits; radius says how soft it is; spacing runs on a 4pt base with a 24 / 32 / 48 / 64 rhythm; motion is fast enough to feel immediate and slow enough to follow.
